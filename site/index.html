A calmer Chatwoot for people who answer tickets all day.

Two skins for the Chatwoot agent dashboard. Paste one snippet into Super Admin and every agent gets them. No fork, no rebuild, nothing to host.

View on GitHub

Tested on Chatwoot 4.16 · MIT license · Light and dark

Fox: one white frame, hairlines and Slack-style messages. Who said what is written on every message.

What changes

The layout stays the Chatwoot your team already knows. The skins change what it emphasizes.

Waiting time on the card

Conversations waiting longer than you allow turn orange, then red. You set the hours.

Private notes you can't miss

Notes get their own color and a written label, in the thread and in the composer, so they never go to a customer by accident.

Unfilled placeholders

A reply with {{order_id}} or [NAME] still in it gets a warning and a wavy underline before you send it.

Labels that read well

Pick a tone per label, hide automation labels from the card and strip prefixes like queue-.

Case card in the contact panel

Show up to four conversation attributes as a 2x2 grid at the top of the panel (Fox).

Small fixes

CC and BCC tucked away, unread count in the tab title, dates stored as 2026-11-05 shown on the right day.

Install in two minutes

You need a Super Admin login on your Chatwoot instance (self-hosted).

  1. Copy the snippet

    Use the button above, or download snippet.html. It holds the CSS and the script inline, so nothing loads from another server.

  2. Paste it into Dashboard Scripts

    Open /super_admin/app_config?config=general, find Dashboard Scripts, paste and save.

  3. Reload the dashboard

    Pick a skin in the footer of the sidebar, or press Alt + Shift + T. Each agent's choice is kept in their browser.

Make it fit your team

Everything is optional. Put this block above the snippet and keep only the keys you need.

<script>
window.WOOT_SKINS = {
  themes: ['fox', 'cilo'],          // first one is the default
  locale: null,                     // 'en' or 'pt-BR'; null follows Chatwoot
  waitHours: [4, 12],               // orange after 4 h, red after 12 h
  labels: {
    critical: '^urgent$',           // shown in red
    hidden: '^(bot-|csat-sent$)',   // hidden on the card
    tones: { billing: 'green', refunds: 'orange', shipping: 'blue' },
    stripPrefix: '^queue-'
  },
  attributeGroups: [['Billing', '^billing_'], ['Other', '.']],
  brandAttribute: 'plan',
  caseCard: [['plan', 'Plan'], ['order_total', 'Order total'],
             ['renewal_date', 'Renewal', 'date'], ['region', 'Region']]
};
</script>

Inline or linked

Anything in Dashboard Scripts runs inside every agent's session, so where the code comes from matters.

Paste it inline Recommended

The code lives in your Chatwoot. Updating is a decision you make: copy the snippet of a new release and paste it again.

Link a pinned version

Load an exact release from jsDelivr with an integrity hash, so the file can't change under you. Never link a moving "latest".

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/airton/woot-skins@v0.1.0/dist/woot-skins.css">
<script src="https://cdn.jsdelivr.net/gh/airton/woot-skins@v0.1.0/dist/woot-skins.js"
        integrity="sha384-…" crossorigin="anonymous"></script>

Safe to try

Read-only

The script reads what Chatwoot already rendered. It never calls the API or changes data.

Off switch

Add ?wsk=off to any dashboard URL to see plain Chatwoot. Delete the snippet to uninstall.

Scoped

Only the agent dashboard is touched. Login, Super Admin and the website widget stay as they are.
